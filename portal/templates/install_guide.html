YVEXOR sur votre écran d’accueil.

Installez l’application, puis créez votre compte ou connectez-vous. Vos projets et vos échanges restent au même endroit.

iPhone / iPad · Safari

Ouvrez cette page dans Safari. Si vous venez d’un SMS ou d’un réseau social, utilisez son menu pour ouvrir le lien dans Safari.

  1. 1. Touchez Partager

    Repérez le carré avec une flèche vers le haut. Selon votre version de Safari, ouvrez d’abord le menu ….

  2. 2. Sur l’écran d’accueil

    Faites défiler les actions du menu et choisissez Sur l’écran d’accueil. Si l’option manque, cherchez-la dans Modifier les actions.

  3. ✓
    3. Confirmez avec Ajouter

    Si Safari propose Ouvrir comme app web, laissez cette option activée, puis touchez Ajouter.

  4. 4. Ouvrez l’icône YVEXOR

    Revenez sur l’écran d’accueil de votre téléphone et touchez la nouvelle icône. Vous pourrez créer votre compte dans l’application.

Android · Chrome
  1. ⋮
    1. Ouvrez le menu de Chrome

    Touchez les trois points, puis Ajouter à l’écran d’accueil ou Installer l’application.

  2. ＋
    2. Confirmez l’installation

    Choisissez Installer si cette option est proposée, puis validez.

  3. 3. Lancez YVEXOR depuis son icône

    Créez votre compte ou connectez-vous : vous êtes dans votre application.

Ordinateur · Chrome ou Edge
  1. ＋
    1. Installez depuis le navigateur

    Utilisez le bouton d’installation ci-dessus s’il apparaît, ou le menu du navigateur : Installer YVEXOR / Applications.

  2. 2. Ouvrez l’application YVEXOR

    Lancez-la depuis le raccourci créé sur votre ordinateur.

Déjà installé ? Fermez cette page et ouvrez l’icône YVEXOR. Installer le site vitrine n’installe pas automatiquement l’espace client.
